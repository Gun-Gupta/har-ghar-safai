## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Styling:** CSS3 & Clean Design Tokens
- **Icons:** Lucide React
- **Language:** TypeScript

## 💻 Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## 📦 Production Build
```bash
npm run build
npm run start
```
